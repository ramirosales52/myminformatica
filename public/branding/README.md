# Logo del comprobante

Colocá tu logo en esta carpeta con el nombre `logo.png`:

`public/branding/logo.png`

Se muestra automáticamente en lugar del ícono de la PC. Usá un PNG cuadrado,
preferentemente con fondo transparente. Si el archivo no existe o no se puede
cargar, se mantiene el ícono de la PC.

En producción, volvé a compilar y publicar después de agregar o reemplazar el logo.
